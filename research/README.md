# ręcovery — pakiet artefaktów badawczych (DEMO)

> **Ważne:** wszystkie pliki w tym katalogu są syntetycznymi materiałami demonstracyjnymi przygotowanymi na potrzeby prototypu HackYeah. Nie zawierają danych pacjentów, pomiarów klinicznych ani zastrzeżonych materiałów Neuralink. Nie należy ich używać do diagnozy, produkcji urządzeń ani podejmowania decyzji medycznych.

## Zawartość

- `cad/hand-exoskeleton-shell-demo.stl` — mały, binarny mock obudowy egzoszkieletu; geometria poglądowa, nie projekt produkcyjny.
- `sketches/prototype-hand.svg` — schematyczny szkic koncepcyjny palców, zawiasów i modułu sterownika.
- `protocol/communication-protocol.md` — fikcyjny protokół transportu dla symulatora, bez implementacji sprzętowej.
- `data/synthetic-rehab-session.json` — wygenerowany zestaw danych testowych; identyfikatory i wartości nie opisują prawdziwych osób.
- `neuro/reading-notes.md` — notatki o publicznie opisywanych kierunkach badań interfejsów mózg–komputer, bez sugerowania związku z firmą Neuralink.

## Status artefaktów

To materiały do narracji, testów interfejsu i makiety przepływu danych. Przed jakimkolwiek użyciem inżynieryjnym potrzebne byłyby m.in. wymagania bezpieczeństwa, walidacja biomechaniczna, przegląd etyczny, anonimizacja oraz konsultacja z wykwalifikowanymi klinicystami i inżynierami.
